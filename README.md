# Mis Ejercicios de Python 🐍

Este repositorio contiene prácticas profesionales de desarrollo en Python.

## Contenido
* **src/ticket_venta.py**: Calculadora de tickets con impuestos.
* **src/authentication.py**: Sistema básico de login.
* **src/rango.py**: Validador de números en rango.

## Cómo ejecutar
Ejecuta el archivo principal o los scripts individuales:
python src/rango.py
