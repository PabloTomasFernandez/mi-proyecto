# Mis Ejercicios de Python 🐍

Este repositorio contiene prácticas profesionales de desarrollo en Python, enfocadas en lógica de programación, condicionales y estructuras de control.

## 📂 Contenido del Proyecto (Carpeta src/)

### Sistemas y Aplicaciones
* **`aplicacion_salud_fitness.py`**: Calculadora de pasos diarios y calorías quemadas.
* **`tienda_linea_descuentos.py`**: Sistema de descuentos basado en monto de compra y membresía.
* **`reserva_hotel.py`**: Cotizador de estadías considerando vistas al mar y tarifas diarias.
* **`sistema_bancario.py`**: Simulación básica de flujo de salida de un sistema seguro.
* **`authentication_system.py`**: Sistema de validación de usuario y contraseña.

### Lógica y Matemáticas
* **`ticket_venta.py`**: Generador de tickets de compra con cálculo de impuestos.
* **`rango.py`**: Validador booleano para números dentro de un rango específico.
* **`operador_ternario.py`**: Ejemplo de simplificación de condicionales (if/else) en una sola línea.

## 🚀 Cómo ejecutar
Para probar cualquiera de los scripts, navega a la carpeta y ejecútalos con Python:

```bash
python src/tienda_linea_descuentos.py
```
